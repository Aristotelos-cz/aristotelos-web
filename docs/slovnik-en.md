# Slovník pojmů pro anglickou verzi webu

Anglické pojmy pocházejí z katalogu funkcí „AristoTelos Features and Functionalities“ (listopad 2026),
tedy z názvů, které používá sama aplikace. České pojmy jsou ty, které používá web a stránka
[Přehled funkcí](../src/content/prehled-funkci.json). Při překladu webu do angličtiny se držte tohoto slovníku,
aby web mluvil stejně jako aplikace.

| Česky (web) | Anglicky (aplikace) | Poznámka |
| --- | --- | --- |
| Veřejný plán | Main schedule | Průběžný provozní plán, který vidí zaměstnanci. Nepřekládat jako „hlavní plán“. |
| Pracovní plány | Working schedules | Rozpracované varianty plánu, ze kterých se zveřejňuje do veřejného plánu. |
| Plánovací období | Planning period | |
| Potřeby (potřeba obsazení) | Staffing requirements | Kolik pracovníků je potřeba v každém intervalu. |
| Požadavky | Requests | Žádosti zaměstnanců: dovolená, výměna směny, změna směny. |
| Pracovní list | Worksheet | |
| Nároky | Entitlements | Například nárok na dovolenou. |
| Volné směny | Open shifts | |
| Výměny směn | Shift trades | |
| Dodržování plánu | Adherence | |
| Znalosti | Skills | Na webu „znalosti“, ne „skilly“ ani „dovednosti“. |
| Fronty | Queues | |
| Výpočty | Calculations | Automatické sestavení plánu. |

Česká pravidla psaní (pracovníci, operátoři, distribuční centra…) jsou v [obsahu a textech](obsah-a-texty.md#slovník-webu).
Slovník doplňujte, kdykoli se na webu objeví nový pojem z aplikace.
